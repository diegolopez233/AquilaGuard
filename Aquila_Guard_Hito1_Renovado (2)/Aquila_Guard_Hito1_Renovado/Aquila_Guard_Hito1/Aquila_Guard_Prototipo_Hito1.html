    Explicar, con datos bajo tu control.

    Privacidad de este prototipo

    El texto ingresado y las fichas se guardan solo en la memoria de esta pestaña. No usamos cookies, almacenamiento local, analítica, API ni base de datos. Al recargar o cerrar la página se pierden. El botón Borrar sesión elimina las fichas, la entrada y el resultado. Un servidor local puede registrar la solicitud de archivos, pero la aplicación no le envía el texto del formulario.

    Usa únicamente datos sintéticos. Esta explicación corresponde al Hito 1. El tratamiento de datos del producto futuro requiere una política y revisión específicas.
