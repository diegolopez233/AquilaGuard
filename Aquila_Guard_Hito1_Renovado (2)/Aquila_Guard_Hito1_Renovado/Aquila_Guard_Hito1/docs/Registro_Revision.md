## Sustitución del paquete

El ZIP renovado contiene una nueva carpeta docs y un README nuevo. Los documentos, láminas, diagramas, guiones, matrices y registros de auditoría anteriores no se reutilizaron como entregables. Se excluyeron las herramientas anteriores de generación de documentos para evitar que regeneren el material sustituido. Se conserva el código de la aplicación, sus assets, la configuración de ejemplo y el modelo propuesto. Las dos capturas del prototipo proceden del paquete recibido y se identifican como tales.

Se incorpora como referencia el PowerPoint que el usuario envió por separado, conservado sin edición, y un PDF de sus nueve láminas. Ese PPTX no es una presentación nueva corregida. Las correcciones sugeridas están en la evaluación y en el guion. El ZIP fuente de Descargas se conserva intacto; los reemplazos están en el ZIP renovado de outputs.

## Verificación realizada

- Se contrastaron los once criterios con RUB.h1 del HTML oficial y los seis entregables con la sección Hito 1.
- Se consultaron las fuentes originales de SUBTEL, la nota técnica de CMF, su campaña con SENAMA y las páginas oficiales de las alternativas tecnológicas.
- Se leyeron el HTML, CSS y JavaScript del prototipo y se compararon por SHA-256 los archivos conservados.
- Se ejecutaron 15 casos de las funciones puras validate y evaluate en Node.js. Los 15 pasaron. Esto comprueba las reglas documentadas, no exactitud contra fraude real.
- Se verificaron archivos requeridos, rutas locales, dimensiones carta y conteo de páginas de la propuesta. El índice se generó en dos pasadas.
- Se renderizaron y revisaron visualmente las páginas de propuesta y evaluación y las láminas de presentación. No se atribuye una apertura exitosa en PowerPoint.

La automatización de PowerPoint no estuvo disponible por una restricción del entorno. El intento de navegador automatizado tampoco completó el inicio. Por ello no se afirma haber realizado una nueva prueba de navegación, móvil o extremo a extremo. Las capturas provienen del material recibido, y el comportamiento documentado se contrastó con el código. El PDF de láminas se generó desde su representación visual; pueden existir diferencias de fuentes frente al original. Compararlo en el equipo de exposición.
